# PS2 Launcher

PS2 Launcher is a modern PlayStation 2 game launcher focused on delivering a cleaner, faster, and more console-like experience while maintaining the compatibility and reliability of Open PS2 Loader.

Built for real PlayStation 2 hardware, PS2 Launcher introduces visual improvements, enhanced game browsing, modernized layouts, and display optimizations designed to make PS2 game management feel more polished and user-friendly.

## Features

- Modern launcher-style interface
- Redesigned game browser
- Cover art support
- Automatic game detection
- USB game loading
- Internal HDD support
- SMB network game loading
- Fast game list navigation
- Custom themes and visual enhancements
- Background artwork support
- Improved game information display
- Memory card integration
- Controller-friendly navigation
- Lightweight and optimized for PS2 hardware

## Display Improvements

PS2 Launcher includes extensive display optimizations to improve image quality on modern displays.

### Resolution Enhancements

- Improved progressive scan presentation
- Enhanced image scaling for modern TVs and HDMI solutions
- Reduced visible horizontal line artifacts compared to standard configurations
- Cleaner menu rendering
- Improved visual sharpness and readability
- Better cover art presentation
- Optimized widescreen layouts
- Smoother UI rendering across supported display modes

These improvements help provide a cleaner and more modern visual experience while preserving compatibility with original PlayStation 2 hardware.
